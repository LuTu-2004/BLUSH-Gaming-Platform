# 🎨 BLUSH FRONTEND MODULES

Thư mục này bao gồm **2 bộ giao diện Frontend** riêng biệt cho ứng dụng **BLUSH**:

---

## 1. 🌐 `web_react/` (Giao diện Web React 19 - Bản Deployed Vercel)
- **Công nghệ:** React 19 + Vite + Lucide Icons + Cyber Dark Mode Layout.
- **Màn hình:** Đầy đủ 12+ màn hình nguyên bản lộng lẫy (Landing, Dashboard, Auth, Matchmaking, Match Feed, Chat 1-1, Profile, Leaderboard, Quests, VIP Upgrade, Checkout, Staff Report Manager, Admin Analytics...).
- **Cách chạy:**
  ```bash
  cd frontend/web_react
  npm install
  npm run dev
  ```

---

## 2. 📱 `mobile_flutter/` (App Di Động Flutter)
- **Công nghệ:** Flutter (Dart) Mobile Application.
- **Màn hình:** Dành cho bạn làm Flutter trong nhóm phát triển App Mobile Android (.apk) và iOS.
- **Cách chạy:**
  ```bash
  cd frontend/mobile_flutter
  flutter pub get
  flutter run
  ```
